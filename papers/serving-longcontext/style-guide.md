# 翻译风格与保真约定

- 原文优先：原编号 (1)–(39)、章节 I–VII、引理/定理/推论、条件、原始引用号均保留。
- 原 PDF 没有算法 1–4。教学流程 1–4 为译者整理，置于附录并明确区分。
- 式子以 LaTeX 记录，由本地 MathJax 3.2.2 排版；不用公式截图。公式中的说明文字中文化，source 仍保留英文。
- b 在系统模型中按表 II 译为本地执行比例；“卸载决策”保留作者名称，并提示两者关系。拍卖中的 a、b 为另一套报价记号。
- 统一使用：大语言模型、LLM 智能体、模型缓存、推理卸载、词元、自洽思维链、思维年龄、消逝因子、交易缩减、双重荷兰式拍卖、迭代式双向拍卖。
- 绿色译注说明背景、动机、直觉；蓝色译注说明符号、公式、推导、证明条件、算法步骤与疑点。所有译注标识“译者”，不计为原文段落。
- 叙述性结论按原文力度翻译；原文未给出的证明、经验假设和实现细节不补成作者结论。
- 参考文献保留原始著录并附题名中译，原编号不改。图内英语保留于原始 artwork，中文图注另行给出。
- 去除双栏断词和页眉页脚；段落按逻辑阅读顺序对齐，浮动图表移至相关章节，页码始终指向原 PDF 页序。
- 在式（4）与其说明、式（3）与（23）、式（14）与（18）、错误表号/引文等位置保留源内差异并标注。
